Steadi Interaction — 바이브코딩 인터랙션 개선

프로토타입으로는 보이지 않았던 것들을 바이브코딩으로 직접 구현해 보며, 0.2초 차이가 사용성과 완성도를 크게 좌우한다는 것을 알 수 있었습니다.

같은 조작을 두 번 녹화했습니다. 왼쪽은 처음 구현, 오른쪽은 다듬은 인터랙션입니다.

글로우 위치의 이동 방법 변경

카드를 따라다니는 글로우를 레이아웃 속성 대신 GPU가 처리하는 이동으로 바꿔, 더 매끄럽게 따라오도록 했습니다.

AS-IS초록 = 다시 그리는 영역 · CPU 4배 느리게

left · top으로 이동

글로우 위치를 레이아웃 속성으로 바꿔 매 프레임 카드 전체를 다시 계산하고 다시 그림

left · top매 프레임 레이아웃복귀 0.6s
TO-BE초록 = 다시 그리는 영역 · CPU 4배 느리게

translate로 이동

같은 움직임을 GPU가 처리하는 translate로 바꿔, 다시 그리는 양이 줄고 마우스를 바로 따라옴

translateGPU 합성복귀 0.4s
